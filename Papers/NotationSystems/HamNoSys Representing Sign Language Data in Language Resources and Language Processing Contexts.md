#papers-annotation 

The paper describes **HamNoSys (Hamburg Notation System)**, a language-independent system for representing sign languages at a mostly phonetic level, and its applications in sign language databases, corpus annotation, and animation generation.

The main points are:
- **Signs are represented through handshape, hand orientation, location, and movement**, including changes occurring sequentially or simultaneously.
- **Handshapes are described using basic shapes and modifiers** for thumb position, finger bending, and individual finger configurations.
- **Movement notation describes changes in posture**, including movement paths and changes in hand configuration.
- **Language-independent notation:** HamNoSys is designed to describe signs from different sign languages using the same symbols.
- **Applications:** Used for searchable sign language dictionaries, corpus transcription, and generating sign language animations.
- **Limitations:** Different HamNoSys descriptions can represent the same sign, making consistent annotation and canonical representations challenging.
